## Abstract

Attempting to fine-tune LLaMA-7B on a 1.2M-example instruction dataset at batch size 256, we encountered training loss divergence in 6 of 10 seeds. Reducing batch size to 128 (with matched optimizer hyperparameters) or 64 eliminated divergence but sacrificed ~30% wall-clock efficiency. This document characterizes the divergence onset and shows that gradient noise scale is the diagnostic.

## Methods

LLaMA-7B (Meta release, HuggingFace port, transformers 4.36.0). Instruction dataset: 1.2M (prompt, response) pairs from our internal compliance review corpus, average response length 220 tokens.

Training: 8× A100 80GB, fp16 with gradient checkpointing, AdamW with β1=0.9, β2=0.999, weight decay 0.01, peak LR 2e-5 with linear warmup 2%, cosine decay. Effective batch size via gradient accumulation.

Seeds: 10 per configuration, batch sizes {64, 128, 256, 512}. 3 epochs each.

## Results

Batch size 64: 10/10 runs converged. Mean eval loss 1.24 ± 0.02.
Batch size 128: 9/10 converged. Mean eval loss 1.21 ± 0.02.
Batch size 256: 4/10 converged. Mean eval loss 1.23 ± 0.02 (among converged); 6/10 diverged at step 800–1500 with loss jumping from 1.8 to 6+ and never recovering.
Batch size 512: 2/10 converged. 8/10 diverged.

Divergent runs showed gradient norms of 80–200 (vs ~5–15 for converged runs) in the 200 steps preceding divergence. Adaptive gradient clipping at 1.0 did not prevent divergence — it only deferred it by ~100 steps before the compounding effect reasserted.

## Discussion

McCandlish et al.'s "gradient noise scale" (GNS) framework predicts the critical batch size beyond which gradient noise becomes too small for SGD stability. We measured GNS ≈ 180 for our LLaMA-7B fine-tuning setup; this sits right at the transition. Batch size 256 is therefore marginal, batch size 512 is past the threshold.

Practical advice: measure GNS on a short warmup run before committing to a batch size. Rule of thumb: target GNS ≥ 2× batch size. If GPU capacity requires larger batches, increase learning rate proportionally AND tighten gradient clipping — but expect higher variance across seeds.

The HuggingFace Trainer default settings do not expose GNS measurement; a short supplementary script using the gradient covariance approximation is sufficient. We include our implementation in the program's internal wiki.

This instability is not visible in published LLaMA fine-tuning recipes we surveyed — most published work uses batch size 32-128 and sidesteps the issue. But for teams with 64+ GPUs targeting large effective batch sizes, the instability is real and under-documented.
